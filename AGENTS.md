# Domain rules that are easy to get wrong

- **Megas:** a team may carry ANY number of Mega-capable Pokémon (Mega formes / Mega Stones). The
  only limit is that ONE Pokémon can Mega Evolve per battle; bringing a Mega and not evolving it is
  normal. Never cap Megas per team, never treat a second Mega as illegal, never strip a Mega Stone
  to "fix" a team. It is fine to mention that only one will evolve in a given game.
